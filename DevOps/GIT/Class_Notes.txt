	- Git Clone 		# To Copy/Clone the entire Remote Repository to the Local Machine
	
	- Git Add 			# To Add the changes from Working Directory to Staging Area 
	
	- Git Commit 		# To Commit the changes from Staging Area to Local Repository
	
	- Git Push 			# To Push the Changes from Local Repository to Remote Repository
	
	- Git Fetch/Pull::
	
			- Both Git Fetch and Git Pull are used to handle the Incremental changes from Remote Repositories
			
		- Git Fetch:
			
			- It used to just check for the incremental changes in the Remote Repository, if there is any Incremental Changes exist, it will update the details only in the Local Repository. Git fetch will NEVER update the Working Directory
			
		- Git Pull:
			- It used to check for the incremental changes in the Remote Repository, if there is any Incremental Changes exist, it will update the details only in the Local Repository as well as in the Working Directory.
				
				git pull = Git Fetch + Git Merge
				
		As a best practise, it is always recommended to use git pull to keep the Local Repo in sync with Remote Repo.
